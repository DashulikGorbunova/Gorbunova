# Unit Tests

## Описание

Этот проект содержит полноценные unit-тесты для репозиторного слоя, покрывающие все CRUD операции.

## Покрытие тестами

### FlowerRepositoryTests
- ✅ GetAllAsync - получение всех цветов
- ✅ GetByIdAsync - получение цветка по ID (существующий и несуществующий)
- ✅ GetByCategoryIdAsync - получение цветов по категории
- ✅ GetByColorAsync - получение цветов по цвету
- ✅ GetFilteredAsync - фильтрация с пагинацией:
  - Базовая пагинация
  - Фильтр по поиску (search)
  - Фильтр по категории
  - Фильтр по доступности
  - Фильтр по диапазону цен
- ✅ AddAsync - создание нового цветка
- ✅ UpdateAsync - обновление существующего цветка
- ✅ DeleteAsync - удаление цветка
- ✅ SaveChangesAsync - проверка сохранения
- ✅ Проверка связей с категориями

### FlowerCategoryRepositoryTests
- ✅ GetAllAsync - получение всех категорий
- ✅ GetByIdAsync - получение категории по ID (существующая и несуществующая)
- ✅ AddAsync - создание новой категории
- ✅ UpdateAsync - обновление существующей категории
- ✅ DeleteAsync - удаление категории
- ✅ SaveChangesAsync - проверка сохранения
- ✅ Проверка сортировки

## Технологии

- **xUnit** - фреймворк для тестирования
- **Testcontainers.PostgreSql** - изолированные тестовые контейнеры PostgreSQL
- **Dapper** - для работы с БД в тестах
- **Moq** - для мокирования зависимостей

## Запуск тестов

### Через Visual Studio
1. Откройте Test Explorer (Test → Test Explorer)
2. Нажмите "Run All Tests"

### Через командную строку
```bash
dotnet test
```

### С подробным выводом
```bash
dotnet test --verbosity normal
```

### С покрытием кода
```bash
dotnet test /p:CollectCoverage=true /p:CoverletOutputFormat=opencover
```

## Структура тестов

Тесты используют интеграционный подход с тестовой БД:
- Каждый тестовый класс использует `DatabaseFixture` для создания изолированного контейнера PostgreSQL
- Перед каждым тестом создаются необходимые таблицы и тестовые данные
- Тесты проверяют реальные операции с БД через Dapper

## Требования

- Docker должен быть запущен (для Testcontainers)
- .NET 8.0 SDK

## Примечания

- Тесты используют Testcontainers для создания изолированных контейнеров PostgreSQL
- Каждый тест выполняется в чистой БД
- Тесты покрывают все CRUD операции и граничные случаи
